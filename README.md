### 一、标题修饰符

使用 # 修饰标题内容，例如# 标题，#的数量决定标题的大小，以及标题字体最大。用一个#修饰，越小的标题等级，标题字体越小。修饰符和文本用空格分隔开才有效。

# 一级标题

## 二级标题

### 三级标题

正文内容直接编辑即可，如果要换行可以用<br>来换行，如果不想换行，可以用转义字符/转义为普通文字：</br>,就不会换行了

有些编辑器只允许用</br>换行

### 二、文本修饰符

1. 使用*包含文本，一对 * 表示斜体，两对表示粗体，三对表示粗斜体

   *斜体样式*

   **粗体**

   ***粗斜体***

2. 使用两对~包含文本，是删除线效果

​	~~删除线效果~~

3. 使用``包含文本，是代码行效果

   `int a[];`

4. 使用5个*号，是分割线：如下

*****

### 三、列表

使用*后接空格，再写文本，会形成无序列表。无序列表可以有多级，用Tab缩进后进入第二级。如果将*换成数字1234就可以形成有序列表。无序列表和有序列表可以混合使用。

* 一级无序列表
  * 二级无序列表
    * 三级无序列表
      * 四级无序列表

1. 一级有序列表

   1. 二级有序列表

      1. 三级有序列表

         1. 四级有序列表

         * 四级无序列表

      * 三级无需列表

   * 二级无序列表

* 一级无需列表

无序列表和有序列表可以混合使用

### 四、引用

使用>后接空格，加文本，构成一级引用，>越多，引用级别越高

> 一级引用
>
> > 二级引用
> >
> > > 三级引用

### 六、表格

设置好表头，数组在单元格中的对齐方式，编写标内容后，会自动生成表格。但是注意表头，对齐方式，表内容三行之间不能有空行，需要进入源代码模式查看

对齐方式：`:---`表示居左对齐，`:---:`表示居中对齐，`---:`居右对齐

表之间的项目有|号分割

表头1|表头2|表头3
:---|:---:|---:
内容1|内容2|内容3
